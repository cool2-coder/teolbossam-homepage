# 털보쌤 숲체험 홈페이지

휴대폰에서 보기 좋은 브랜드 홈페이지와 **숲 일지 자동화**가 함께 들어 있어요.

| 주소 | 누가 | 하는 일 |
|---|---|---|
| `/` | 누구나 | 브랜드 소개 (핵심가치, 다섯 가지 힘) |
| `/j/아이코드` | 학부모님 | 우리 아이 숲 일지. 로그인 없이 문자 속 링크로 들어와서 사진 보기, 원본 저장, 답장 남기기 |
| `/admin` | 털보쌤 | 수업 만들기, 사진 나누기, 아이별 기록, 문자 발송, 답장 현황 |

## 털보쌤이 매주 하는 일

1. **새 수업 만들기**: 주제와 집 미션을 적어요. 명단의 아이들이 모두 출석으로 들어가요.
2. **사진 나누기**: 수업 사진을 한꺼번에 올리고 사진마다 나온 아이 이름을 눌러요. 단체 사진은 여러 명을 누르면 돼요.
3. **아이별 기록**: 출석 여부, 털보쌤 한마디, 오늘 기른 힘을 적고 "저장하고 다음 아이"를 눌러요.
4. **발행**: 버튼 하나로 출석한 가족 모두에게 이름이 들어간 문자가 가요.

이후는 자동이에요.
- 학부모님 답장은 아이 일지와 관리 화면에 모여요. `TEACHER_PHONE`을 넣으면 답장이 올 때 알림 문자도 받아요.
- 정한 요일(기본: 목요일) 저녁 7시쯤, 답장 안 한 가족에게만 재알림이 가요.

## 처음 설치하기 (Vercel 하나로)

1. Vercel → **Add New → Project** → GitHub의 `teolbossam-homepage` 저장소를 **Import**.
2. **Environment Variables**에 `ADMIN_PASSWORD`(관리자 비밀번호)를 넣고 **Deploy**.
3. 프로젝트 → **Storage → Create Database → Neon(Postgres)** → 이 프로젝트에 연결(Connect).
   `DATABASE_URL`이 자동으로 들어가요.
4. **Deployments → 맨 위 배포 ⋯ → Redeploy**. 배포할 때 DB 표가 자동으로 만들어져요.
5. `https://프로젝트이름.vercel.app/admin`에 들어가서 **아이 명단**부터 등록해요.

문자 링크 주소는 Vercel 주소가 자동으로 쓰여요. 나중에 도메인을 사면 `SITE_URL`에 넣어 주세요.

**문자 자동 발송 (나중에)**: 솔라피에 가입하고 발신번호를 등록한 뒤 `SOLAPI_API_KEY`, `SOLAPI_API_SECRET`, `SMS_FROM`, `CRON_SECRET`을 넣으면 켜져요.
그전까지는 문자가 나가지 않고 관리 화면의 ‘문자 기록’에만 남아서 비용이 들지 않아요.

## 개발

```bash
cp .env.example .env.local   # 값 채우기
npm install
npm run db:migrate
npm run db:seed              # 예시 아이 12명과 수업 1개 (테스트용)
npm run dev
```

- Next.js 15 (App Router) + Postgres (`postgres` 패키지)
- 사진은 브라우저에서 긴 변 1600px로 줄여서 DB에 저장해요. 별도 저장소 서비스가 필요 없어요.
- 학부모 링크는 추측하기 어려운 아이별 코드로 만들어지고, 검색엔진에 노출되지 않아요.
